# Package index

## Modules

These functions produce longitudinal visualizations and in some cases an
accompanying descriptive summary table.

- [`g_boxplot()`](https://insightsengineering.github.io/goshawk/reference/g_boxplot.md)
  : Function to create a boxplot.
- [`g_correlationplot()`](https://insightsengineering.github.io/goshawk/reference/g_correlationplot.md)
  : Function to create a correlation plot.
- [`g_density_distribution_plot()`](https://insightsengineering.github.io/goshawk/reference/g_density_distribution_plot.md)
  : Function to create a density distribution plot.
- [`g_lineplot()`](https://insightsengineering.github.io/goshawk/reference/g_lineplot.md)
  : Function to create line plot of summary statistics over time.
- [`g_spaghettiplot()`](https://insightsengineering.github.io/goshawk/reference/g_spaghettiplot.md)
  : Function to create a spaghetti plot.
- [`t_summarytable()`](https://insightsengineering.github.io/goshawk/reference/t_summarytable.md)
  : Function to create a table of descriptive summary statistics to
  accompany plots.

## Deprecated
